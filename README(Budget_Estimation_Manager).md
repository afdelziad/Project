💰 Dynamic Budget Manager (C)

A console-based application developed in C to manage budget estimates using dynamically allocated arrays.

This project allows users to initialize, fill, add, delete, display, and sort budget estimates through an interactive menu.

🚀 Features

Initialize Array: Create a dynamically allocated array using calloc().
Fill Array: Enter budget estimates.
Add Estimate: Add a new estimate using realloc().
Delete Estimate: Remove an estimate by its index.
Display Estimates: Display all stored budget estimates.
Sort Estimates: Sort estimates in ascending order.
Memory Management: Free dynamically allocated memory using free().

🛠️ Technologies & Concepts

Language: C
Libraries: stdio.h, stdlib.h
Pointers: Pointer manipulation and memory addresses.
Dynamic Memory Allocation: calloc(), realloc(), free().
Functions: Modular programming and function decomposition.
Arrays: Dynamic arrays and element manipulation.
Sorting Algorithms: Comparison-based sorting.
Control Structures: Loops, conditions, and switch statements.
